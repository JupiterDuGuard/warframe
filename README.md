# Калькулятор урона Warframe

Сайт: https://jupiterduguard.github.io/warframe/

Статический сайт на GitHub Pages: данные собирает Python-скрипт, считает всё браузер.
Главная — калькулятор урона оружия по противнику (`index.html`), калькулятор яда Ораксии — `oraxia.html`.
Сайт ставится как приложение (PWA: Chrome/Edge «Установить», на телефоне «Добавить на главный экран») и работает без интернета.

## Структура

```
index.html            калькулятор урона (интерфейс: js/app.js, js/store.js, css/app.css)
js/aleca.js           импорт из AlecaFrame: lastData.dat расшифровывается в браузере, никуда не отправляется
js/share.js           ссылка на билд: состояние → deflate → base64url в «#b=…»
oraxia.html           калькулятор яда Ораксии
sw.js, manifest.webmanifest, icons/   PWA: офлайн-кэш и установка
data/                 собранные данные (JSON), их читает сайт
  meta.json           версия и дата данных
  weapons/*.json      оружие: атаки, урон по типам, крит, статус, Инкарнон
  mods/*.json         моды: эффекты по рангам {stat, value, bucket, condition}
  arcanes/*.json      мистификаторы
  warframes.json      фреймы
  enemies.json        враги: здоровье, щиты, броня, базовый уровень, множители частей тела
  damage.json         типы урона и модификаторы фракций (текущая система урона)
  incarnon.json       эволюции Инкарнона: перки по уровням с эффектами (tools/incarnon.py)
  manual/             вручную со ссылками на вики: рост статов врагов, формула брони, осколки архонтов, баффы
  overrides/          ручные правки автоматического разбора
tools/
  build_data.py       сборка data/
  lualite.py          разбор Lua-таблиц из модулей данных вики
  unparsed.md         отчёт: что скрипт не смог разобрать
TODO_VERIFY.md        неподтверждённые механики
```

## Движок и тесты

`js/engine/` — чистые функции без DOM: `calc(build, target, data, opts)` возвращает урон по типам, доп. удары, тики статусов,
DPS, время на убийство и разбор формулы (`steps`). Эталоны в `tests/cases.mjs`: замеры в Симулякре, пресеты калькулятора
Ораксии, примеры с вики.

```
node --test tests/              # Node.js 18+
```
Без Node: открыть `tests/index.html` через локальный сервер (`python -m http.server`) или на сайте: `/warframe/tests/`.

## Импорт из AlecaFrame

Кнопка «Импорт из AlecaFrame» → файл `%LOCALAPPDATA%\AlecaFrame\lastData.dat` → выбрать оружие или фрейм и конфиг (A/B/C).
Подтягиваются моды с рангами, эксилус, мистификаторы, стойка, полярности слотов, катализатор/реактор, эволюции Инкарнона,
осколки и Helminth. Файл расшифровывается в браузере (ключ из открытого
[парсера Sainan](https://github.com/Sainan/alecaframe-inventory-parser)) и никуда не уходит.

Раскладка `Configs[].Upgrades`: оружие — 0–7 моды (в игре слева направо идут 7→0), 8 эксилус, 9 мистификатор;
ближний бой — 8 стойка, 9 эксилус, 10 мистификатор; фрейм — 8 аура, 9 эксилус, 10–11 мистификаторы.

## Обновить данные

```
python tools/build_data.py            # кэш скачанного живёт 12 ч
python tools/build_data.py --refresh  # скачать всё заново
```

Нужен только Python 3.10+, без внешних библиотек. После сборки — закоммитить `data/` и `tools/unparsed.md`.
