# Калькулятор урона Warframe

Сайт: https://jupiterduguard.github.io/warframe/

Статический сайт на GitHub Pages: данные собирает Python-скрипт, считает всё браузер.
Сейчас на сайте калькулятор яда Ораксии; универсальный калькулятор собирается по этапам (см. ниже).

## Структура

```
index.html            сайт
data/                 собранные данные (JSON), их читает сайт
  meta.json           версия и дата данных
  weapons/*.json      оружие: атаки, урон по типам, крит, статус, Инкарнон
  mods/*.json         моды: эффекты по рангам {stat, value, bucket, condition}
  arcanes/*.json      мистификаторы
  warframes.json      фреймы
  enemies.json        враги: здоровье, щиты, броня, базовый уровень, множители частей тела
  damage.json         типы урона и модификаторы фракций (текущая система урона)
  manual/             вручную со ссылками на вики: рост статов врагов, формула брони
  overrides/          ручные правки автоматического разбора
tools/
  build_data.py       сборка data/
  lualite.py          разбор Lua-таблиц из модулей данных вики
  unparsed.md         отчёт: что скрипт не смог разобрать
TODO_VERIFY.md        неподтверждённые механики
```

## Обновить данные

```
python tools/build_data.py            # кэш скачанного живёт 12 ч
python tools/build_data.py --refresh  # скачать всё заново
```

Нужен только Python 3.10+, без внешних библиотек. После сборки — закоммитить `data/` и `tools/unparsed.md`.

## Источники

- [WFCD warframe-items](https://github.com/WFCD/warframe-items) (MIT): моды и мистификаторы по рангам, русские названия.
- [Warframe Wiki](https://wiki.warframe.com) (модули `Module:*/data`, лицензия CC BY-SA): оружие, фреймы, враги, типы урона и фракции.
- Warframe и все связанные материалы принадлежат Digital Extremes.

## Этапы

1. ✅ Изучить данные, схема и структура.
2. ✅ Пайплайн данных, разбор модов и мистификаторов, overrides.
3. Движок урона оружия + тесты (`node --test`).
4. Интерфейс оружия и противника.
5. Фрейм: статы, моды, осколки, мистификаторы, Helminth, ауры, эффективное здоровье.
6. Баффы способностей, фокус, условные стаки, баффы союзников.
7. Ближний бой, Инкарноны, экзальт-оружие.
8. Вклад модов, пороговые уровни, сравнение A/B, ссылка на билд, вместимость, импорт из AlecaFrame, PWA.
